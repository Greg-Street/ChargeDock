# 使用与适配

## 日常使用

单击托盘图标打开面板，右键可刷新、设置、暂停提醒或退出。低电量阈值与开关按类别独立配置。开机启动默认关闭；开启后请保持程序路径不变。

设备无回复时保留最近一次读数并标注状态；接收器断开不显示成 0%。接电时隐藏不可靠百分比，拔线或大幅变化后先等待稳定确认。键盘的外接电源状态不等于确认正在充电，耳机协议没有已验证的充电标志。

## 扩展适配

- `core.MODELS` 定义类别名称，`ui.DeviceCard.SUBTITLES` 定义说明，`locales/` 保存翻译。
- `device_proto.py` 定义通用接收器匹配条件和电量查询协议；VID/PID、Usage、报告长度属于技术适配参数，不是设备序列号。
- 只向已经确认匹配的接口发送已知查询，不对未知接口试写。
- 新适配应检查有效回复、错误回复、超时、离线、外接电源与提醒策略。

公开反馈只使用虚构读数或经过处理的截图。不要附上个人设备组合、原始 HID 实例路径、序列号、设置文件、完整枚举结果或运行诊断记录。
